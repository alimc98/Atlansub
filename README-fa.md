# Atlansub — زیرنویس‌ساز فارسی

اپلیکیشن محلی برای ساخت زیرنویس فارسی از ویدیو یا فایل صوتی، با خروجی‌های آماده برای Adobe Premiere.

همه‌چیز آفلاین و روی همین سیستم اجرا می‌شود؛ هیچ فایلی به اینترنت فرستاده نمی‌شود.

[English README](README.md)

## اجرا

### ویندوز — با یک کلیک

روی `run.bat` دوبار کلیک کنید. در اولین اجرا خودش همه‌چیز را آماده می‌کند:

۱. محیط مجازی `.venv` را می‌سازد و کتابخانه‌های پایتون را نصب می‌کند.
۲. اگر ffmpeg روی سیستم نباشد، نسخه‌ی آماده‌ی آن را در `tools\ffmpeg` دانلود می‌کند.
۳. مدل گفتار `large-v3-turbo` (حدود ۱٫۶ گیگابایت) را در `models\large-v3-turbo` دانلود می‌کند.
۴. سرور را اجرا می‌کند و مرورگر را روی `http://127.0.0.1:7861` باز می‌کند.

اجراهای بعدی سریع‌اند و فقط سرور را بالا می‌آورند. نیازی به ویرایش هیچ مسیری نیست و پروژه روی هر درایوی می‌تواند باشد.

### لینوکس / مک

```bash
chmod +x run.sh
./run.sh
```

`run.sh` همین کارها را انجام می‌دهد؛ فقط ffmpeg را از قبل نصب کنید (`sudo apt install ffmpeg` یا `brew install ffmpeg`).

### نصب دستی (همه‌ی سیستم‌ها)

```bash
python -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python -m app.setup                # دانلود ffmpeg (ویندوز) و مدل
python -m app.server
```

دستور `python -m app.setup` را هر چند بار هم که اجرا کنید مشکلی پیش نمی‌آید؛ فقط چیزهای نبود را دانلود می‌کند.

اگر مدل را از قبل دارید، مسیرش را در متغیر `WHISPER_MODEL` بگذارید (بخش «نکته‌های فنی»).

برای بستن برنامه، پنجره‌ی کنسول را ببندید. اگر مرورگر باز نشد، آدرس بالا را دستی باز کنید.

## استفاده

۱. ویدیو یا فایل صوتی را داخل کادر بکشید و رها کنید (یا کلیک کنید و انتخاب کنید).
۲. گزینه‌ها را تنظیم کنید:
   - **دقت رونویسی:** «دقیق» برای کار نهایی، «سریع» برای پیش‌نمایش.
   - **زبان گفتار:** فارسی (یا تشخیص خودکار).
   - **فایل SRT آماده‌ی پریمیر:** متن از پیش شکل‌گرفته تا پریمیر حروف فارسی را به‌هم نریزد. پیش‌فرض روشن است.
   - **لایه‌ی شفاف ProRes 4444:** یک ویدیوی شفاف با زیرنویس رندرشده؛ برای انداختن روی تایم‌لاین. کند است و حجم دارد، پس فقط وقتی لازم دارید روشن کنید.
۳. «شروع ساخت زیرنویس».
۴. بعد از پایان، فایل‌ها را دانلود کنید. متن هر کیو را هم می‌توانید در بخش «ویرایش زیرنویس» اصلاح کنید؛ با ذخیره، فایل‌های SRT بازسازی می‌شوند.

## خروجی‌ها

| فایل | کاربرد |
|---|---|
| `<نام>.fa.srt` | زیرنویس معمولی برای VLC و پلیرها |
| `<نام>.fa.premiere.srt` | مخصوص پریمیر؛ حروف از پیش شکل‌گرفته و در ترتیب بصری |
| `<نام>.fa.overlay.mov` | لایه‌ی شفاف ProRes 4444 با آلفا (در صورت فعال بودن) |
| `<نام>.fa.txt` | متن ساده‌ی گفتار |

### در پریمیر

- **روش مطمئن:** فایل `overlay.mov` را بالای کلیپ اصلی روی تایم‌لاین بیندازید. سکوئنس را هم‌اندازه‌ی خود ویدیو بسازید.
- **روش سبک:** فایل `premiere.srt` را Import کنید و به‌عنوان Caption روی تایم‌لاین بگذارید. اگر متن را داخل پریمیر ویرایش کنید به‌هم می‌ریزد؛ در همان اپ ویرایش و دوباره ذخیره کنید.
- اگر پریمیر شما خودش از راست‌به‌چپ پشتیبانی می‌کند، همان `fa.srt` ساده را استفاده کنید.

## نکته‌های فنی

- مدل: `large-v3-turbo` (faster-whisper، CPU، int8) به‌صورت پیش‌فرض در `models/large-v3-turbo` داخل خود پروژه.
- اگر مدل را از قبل دارید، کافی است مسیر آن را در `WHISPER_MODEL` بگذارید؛ مثلاً `set WHISPER_MODEL=D:\models\large-v3-turbo-local`.
- اولین اجرا مدل را در حافظه بار می‌کند (۲۰ تا ۴۰ ثانیه)؛ اجراهای بعدی سریع‌ترند.
- زمان تقریبی رونویسی: حدود ۳ تا ۵ برابر سرعت واقعی ویدیو (روی سیستم ۸ هسته‌ای).
- زمان تقریبی رندر لایه‌ی ۴K: حدود ۴ برابر مدت ویدیو؛ مثلاً ۲ دقیقه ویدیو ≈ ۸ تا ۱۰ دقیقه.
- پورت پیش‌فرض ۷۸۶۱ است؛ اگر اشغال باشد، برنامه پورت بعدی را انتخاب می‌کند.
- فایل‌های پروژه‌ها در پوشه‌ی `jobs\` ذخیره می‌شوند. با دکمه‌ی «پاک کردن فایل‌ها» حذف می‌شوند.
- حجم دانلود اولین اجرا: حدود ۵۰۰ مگابایت کتابخانه + ۱۱۰ مگابایت ffmpeg (ویندوز) + ۱٫۶ گیگابایت مدل. اینترنت فقط در همان اجرای اول لازم است.

## ساختار

```
Atlansub\
  app\
    server.py      سرور FastAPI و APIها
    pipeline.py    رونویسی، ساخت خروجی‌ها، رندر لایه
    srt_utils.py   پارس/ساخت SRT، نرمال‌سازی فارسی، نسخه‌ی پریمیر
    ass_gen.py     ساخت ASS برای رندر
    setup.py       آماده‌سازی اولیه: دانلود ffmpeg و مدل
    static\        رابط کاربری (HTML/CSS/JS)
    fonts\         فونت وزیرمتن
  jobs\            پروژه‌ها و خروجی‌ها
  models\          مدل دانلودشده (خارج از گیت)
  tools\           ffmpeg دانلودشده در ویندوز (خارج از گیت)
  run.bat          اجرای یک‌کلیکی در ویندوز
  run.sh           اجرا در لینوکس/مک
  requirements.txt
```
